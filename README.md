# MSH Sounds And Projects

A premium, dark-themed marketing website for **MSH Sounds And Projects**, a car-audio
fitment business based in Pretoria, South Africa.

- **Live site:** https://mshsounds.co.za
- **Built with:** Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 ·
  next-themes (dark/light) · lucide-react

## Features
- 6 pages: Home, About, Services, Shop, Gallery, Contact
- Glassmorphism hero with equalizer animation and red/gold brand palette
- Gallery with category tabs, lightbox, and a "Full Builds" video section
  (Facebook/TikTok embeds, click-to-play, one-at-a-time)
- Contact form with WhatsApp click-to-chat, Google Maps embed, and reviews widget
- 170+ images across 9 categories (converted/optimized from HEIC)

## Getting Started
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint     # eslint
```

## Deploy
Deployed on Vercel (auto-deploy from the GitHub `master` branch).
